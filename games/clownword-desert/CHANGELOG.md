# Changelog

## [2.0.0] - 2026-07-30

### Added

- Student name profiles
- Automatic numeric and letter grading
- Saved browser-based student records
- Per-session and all-record CSV export
- Individual target words above every clown
- Slow-motion spelling focus mode
- Browser pronunciation controls
- Missed-word correction and review weighting
- Tent seal words
- Multi-phase Ringmaster bosses
- Runner, tank, mime, juggler, balloon, and standard clown types
- Custom word lists
- Four named desert regions
- Day/night cycle
- Mobile direction controls and on-screen keyboard
- High-contrast and reduced-motion modes
- Pause, fullscreen, print-report, and records screens
- Expanded in-game and README instructions

### Changed

- Correct spelling now targets the specific clown or tent carrying the word.
- Tents require seal words followed by a boss battle.
- The end screen is now a complete educational session report.
- Student mistakes are corrected and repeated instead of serving only as penalties.

## [1.0.0] - 2026-07-30

- Initial open-world desert spelling game.
- Arrow-key movement and global sight-word attacks.
