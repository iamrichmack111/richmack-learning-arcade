# Equation Outbreak: Road Scholar

A browser-based Three.js educational action-driving game.

## Fast start

### Linux or macOS

Open a terminal in this folder and run:

```bash
./start-game.sh
```

### Windows

Double-click `start-game.bat`.

The launcher opens the game in your browser. Keep its terminal window open while playing. You can also run `python3 launcher.py` manually.

## Controls

### Driving

- **W / Up Arrow:** accelerate
- **S / Down Arrow:** reverse
- **A / D or Left / Right:** steer
- **Space:** brake
- **M:** solve a math problem for gas
- **P:** spell a word for ammo and upgrades
- **E:** begin a mission inside a yellow mission beacon
- **Esc:** pause

### Combat

- **WASD:** move
- **Mouse:** aim
- **Left click:** shoot
- **Shift:** sprint
- **P:** spell for ammo
- **E:** return to the car after clearing a mission
- **Esc:** release the mouse or pause

## Learning and grading

- Math questions adjust to the selected school grade and replenish fuel.
- Spelling answers replenish ammo and unlock stronger cars and weapons.
- Mission completion, accuracy, and survival contribute to the live score and final letter grade.
- A text grade report can be downloaded from the pause screen or completion screen.

## Game features

- Procedurally generated 3D city with buildings, streets, parks, traffic lights, and weather atmosphere
- AI traffic that follows roads, reacts to lights, and can collide with the player
- Four player-car tiers and four weapon tiers
- Three outbreak missions with increasingly difficult zombie minions
- Driving mode and third-person combat mode
- Minimap, speedometer, fuel, health, ammo, mission guidance, sound effects, and score tracking

## Browser note

The game loads Three.js 0.185.1 from jsDelivr, so an internet connection is required when the page starts. All city objects, cars, zombies, particles, sounds, and gameplay are generated by the included source files; there are no separate model or audio downloads.
