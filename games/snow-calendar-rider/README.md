# Snow Calendar Rider 3D

A Three.js educational snow-riding game.

## Gameplay
- Dodge trees, rocks, and logs.
- Collect Monday through Sunday in order.
- Then collect January through December in order.
- Earn 10 coins for every correct pickup.
- Complete each set to increase the riding speed.
- You have three lives.

## Controls
- A / Left Arrow: steer left
- D / Right Arrow: steer right
- Space: jump
- P: pause
- Touch controls are included.

## Run
Open a terminal in this folder and run:

    python3 -m http.server 8080

Then visit:

    http://localhost:8080

The game loads Three.js from jsDelivr, so the browser needs internet access when opening the game.
